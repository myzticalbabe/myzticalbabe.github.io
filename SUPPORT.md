# Support

## Where to ask

- **Using the site, or stuck on an exercise** — open an issue at
  <https://github.com/myzticalbabe/myzticalbabe.github.io/issues/new>. Say which page
  you were on and paste the full output you got.
- **A bug** — use the bug report form. A minimal reproduction gets a fix far faster
  than a description of symptoms.
- **A security problem** — do not open a public issue; follow [SECURITY.md](SECURITY.md).
- **An accessibility barrier** — see [ACCESSIBILITY.md](ACCESSIBILITY.md) and open an
  issue. Name the page and the assistive technology you used.
- **Running this in a classroom or club** — read [STEM.md](STEM.md) first; it has the
  session plan and the vocabulary list.

## What to include

1. What you expected to happen.
2. What happened instead — the exact text, not a paraphrase.
3. The page or click path that produces it.
4. Your operating system and browser version.

## What this project is not

It is not a commercial product and there is no paid support tier. Maintainers answer
when they can. A question that goes unanswered for a week is not a rejection — open
the issue again with more detail rather than giving up quietly.

## For learners

If you are a student using this site for a class or a club project, you are welcome to
ask questions here. Nobody will be told that your question was too basic.
