# YGGDRASIL Forest Index

**Interactive domain atlas for the myzticalbabe ecosystem.** This repository serves as the GitHub Pages deployment target for the YGGDRASIL domain forest visualization.

## Purpose

The YGGDRASIL Forest Index renders interactive domain trees from the Azazael ecosystem. Each domain represents a distinct architectural concern spanning multiple code roots — not a single directory. The forest is generated from live code censuses and renders in-browser using D3.js force-directed graphs.

## Updating Atlas Data

The atlas data is generated by `tools/domain_trees.py` in the `azazael` monorepo:

```bash
# From azazael monorepo root:
python tools/domain_trees.py              # Generates all domain atlases + forest_manifest.json
python tools/domain_trees.py --check      # Table: totals per domain
```

The output writes to `~/yggdrasil_forest/` which is then synced to this repository for deployment.

### Sync Procedure

1. Run `python tools/domain_trees.py` in the azazael monorepo
2. Copy `~/yggdrasil_forest/*.json` to this repository's `data/` directory
3. Commit and push — GitHub Pages deploys automatically via `.github/workflows/pages-deploy.yml`
