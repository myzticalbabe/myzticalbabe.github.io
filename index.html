Ecosystem Overview

The YGGDRASIL Forest Index visualizes the 20+ repositories of the myzticalbabe ecosystem as an interactive domain forest. Each domain represents a distinct architectural concern spanning multiple code roots — not a single directory. The forest is generated from live code censuses using tools/domain_trees.py in the azazael monorepo.
